# Task Monitoring Configuration

后台任务监控配置与阈值定义

## 监控维度

### 1. 时间维度

| 指标 | 正常范围 | 异常阈值 | 处理动作 |
|------|----------|----------|----------|
| 执行时长 | < 预估时间 | > 预估时间 2x | 记录警告，检查进度 |
| 等待响应 | < 30s | > 60s 无响应 | 可能卡死，考虑重启 |
| 总运行时间 | 任务相关 | 无限增长 | 检查是否死循环 |

### 2. 资源维度

| 指标 | 正常范围 | 异常阈值 | 处理动作 |
|------|----------|----------|----------|
| CPU 使用 | 0-80% | 持续 100% > 30s | 可能死循环，记录日志 |
| 内存使用 | < 80% | > 90% | 内存泄漏风险，警告 |
| 磁盘 IO | 正常波动 | 持续高 IO | 检查日志量 |

### 3. 输出维度

| 指标 | 正常模式 | 异常模式 | 处理动作 |
|------|----------|----------|----------|
| stdout | 正常输出 | 大量重复内容 | 可能死循环 |
| stderr | 空/少量 | 持续输出错误 | 记录到 ERRORS.md |
| exit code | 0 | 非 0 | 记录错误，触发自改进 |

### 4. 进度维度

| 指标 | 正常范围 | 异常阈值 | 处理动作 |
|------|----------|----------|----------|
| 里程碑更新 | 按预期推进 | > 5min 无更新 | 检查是否卡住 |
| 进度百分比 | 稳步增长 | 长时间 0% 或 100% | 检查任务状态 |

### 5. 状态维度

| 状态 | 说明 | 处理动作 |
|------|------|----------|
| running | 正常运行 | 继续监控 |
| completed | 正常完成 | 记录结果 |
| failed | 执行失败 | 记录错误，触发自改进 |
| timeout | 超时终止 | 分析原因，考虑重试 |
| zombie | 僵尸进程 | 清理，记录异常 |

### 6. 结果维度

| 检查项 | 正常 | 异常 | 处理动作 |
|--------|------|------|----------|
| 输出文件存在 | ✓ | ✗ | 记录错误，检查原因 |
| 文件大小合理 | ✓ | 0 字节或异常大 | 检查内容完整性 |
| 数据格式正确 | ✓ | 解析失败 | 记录错误，检查生成逻辑 |

## 监控实现

### 检查子代理状态

```bash
# 列出所有子代理
subagents(action=list)

# 查看特定子代理日志
subagents(action=list, target="session-id")
```

### 检查后台进程

```bash
# 列出后台进程
process(action=list)

# 获取进程日志
process(action=log, sessionId="session-id")

# 终止异常进程
process(action=kill, sessionId="session-id")
```

### 异常自动处理

当检测到异常时，系统自动执行：

1. **记录错误** → `.learnings/ERRORS.md`
2. **分析原因** → 检查日志、输出、资源
3. **自改进学习** → 更新 AGENTS.md / TOOLS.md
4. **重新规划**（如需要）→ 调整策略重试
